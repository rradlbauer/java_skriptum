# 05.3 Methoden überladen (Overloading)

**Methodenüberladung** bedeutet, dass mehrere Methoden **denselben Namen** haben, aber **unterschiedliche Parameter** (Typ, Anzahl oder Reihenfolge). In Python ist das nicht direkt möglich – dort brauchst du Standardparameter oder `*args`.

## Beispiel: Dosierungsberechnung

```java
public class DosageCalculator {

    // Simple dosage by weight
    public double calculateDose(double weight) {
        return weight * 0.02;  // 2% of body weight
    }

    // Dosage with custom factor
    public double calculateDose(double weight, double factor) {
        return weight * factor;
    }

    // Dosage by age and weight (for children)
    public double calculateDose(int age, double weight) {
        if (age < 12) {
            return weight * 0.015;  // reduced dose
        } else {
            return weight * 0.02;
        }
    }
}
```

Verwendung:

```java
DosageCalculator calculator = new DosageCalculator();

double d1 = calculator.calculateDose(70.0);          // 1st method
double d2 = calculator.calculateDose(70.0, 0.025);   // 2nd method
double d3 = calculator.calculateDose(10, 30.0);      // 3rd method (int, double)
```

## Wie erkennt Java die richtige Methode?

Der Compiler entscheidet anhand der **Parameterliste** (Anzahl und Typ), welche Methode aufgerufen wird. Das passiert bereits zur **Compile-Zeit**.

```java
calculateDose(70.0)         // → 1st method (double)
calculateDose(70.0, 0.025)  // → 2nd method (double, double)
calculateDose(10, 30.0)     // → 3rd method (int, double)
```

## Konstruktor-Überladung

Besonders nützlich ist das Überladen von Konstruktoren. So kannst du verschiedene Initialisierungsmöglichkeiten anbieten:

```java
public class Patient {
    private String name;
    private int age;
    private double height;

    // 1. Constructor: all parameters
    public Patient(String name, int age, double height) {
        this.name = name;
        this.age = age;
        this.height = height;
    }

    // 2. Constructor: name only (other values with defaults)
    public Patient(String name) {
        this.name = name;
        this.age = 0;
        this.height = 0.0;
    }

    // 3. Constructor: name and age
    public Patient(String name, int age) {
        this.name = name;
        this.age = age;
        this.height = 0.0;
    }
}
```

## this() – Konstruktor von Konstruktor aufrufen

Mit `this(...)` kann ein Konstruktor einen anderen Konstruktor derselben Klasse aufrufen – das vermeidet Code-Wiederholung:

```java
public class Patient {
    private String name;
    private int age;
    private double height;

    // Main constructor
    public Patient(String name, int age, double height) {
        this.name = name;
        this.age = age;
        this.height = height;
    }

    // Calls main constructor with default values
    public Patient(String name) {
        this(name, 0, 0.0);  // this() must be the FIRST statement
    }

    public Patient(String name, int age) {
        this(name, age, 0.0);
    }
}
```

## Vergleich mit Python

In Python kannst du nicht mehrere Methoden mit demselben Namen definieren – die letzte Definition gewinnt:

```python
# Python: not possible
class Dosage:
    def calculate(self, weight):      # gets overwritten
        return weight * 0.02

    def calculate(self, weight, factor):  # overwrites the first
        return weight * factor
```

Python verwendet stattdessen Standardparameter oder `*args`/`**kwargs`.
