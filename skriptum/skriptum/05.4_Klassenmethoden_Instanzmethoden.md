# 05.4 Klassenmethoden, Instanzmethoden, Klassenattribute, Instanzattribute

Das `static`-Schlüsselwort in Java ist der zentrale Unterschied zwischen "gehört zur Klasse" und "gehört zum Objekt". 
In Python gibt es das Konzept von `@classmethod` und `@staticmethod`.

## Instanzmethoden und Instanzattribute

Instanzmethoden und -attribute gehören zu einem **konkreten Objekt**. Sie werden ohne `static` deklariert:

```java
import java.time.LocalDateTime;

public class Patient {
    private String name;        // Instance attribute
    private LocalDate birth;            // Instance attribute

    public Patient(String name, LocalDate birth) {
        this.name = name;
        this.birth = birth;
    }

    public void display() {     // Instance method
        System.out.println(name + " (" + birth + ")");
    }
}
```

Verwendung:

```java
Patient p1 = new Patient("Anna", LocalDate.of(1998, 5, 12));
Patient p2 = new Patient("Ben", LocalDate.of(1990, 10, 5));
p1.display();  // Anna (1998-05-12)
p2.display();  // Ben (1990-10-05)
```

## Klassenmethoden und Klassenattribute (static)

Mit `static` deklarierte Member gehören zur **Klasse selbst**, nicht zu einzelnen Objekten:

```java
public class Patient {
    private static int patientCount = 0;  // Class attribute
    private String name;

    public Patient(String name) {
        this.name = name;
        patientCount++;  // Incremented for each new object
    }

    public static int getPatientCount() {  // Class method
        return patientCount;
    }
}
```

Verwendung:

```java
Patient p1 = new Patient("Anna");
Patient p2 = new Patient("Ben");

System.out.println(Patient.getPatientCount());  // 2
```

## Wann verwendet man static?

`static` verwendest du, wenn eine Methode oder ein Attribut **nicht an ein bestimmtes Objekt gebunden** ist:

| Verwendung | Beispiel |
|------------|----------|
| **Zähler/Statistiken** | Anzahl aller erzeugten Objekte einer Klasse |
| **Hilfsmethoden** | Mathematische Berechnungen ohne Objektzustand |
| **Konstanten** | Fixe Werte wie `MAX_HEIGHT`, `PI` |
| **Factory-Methoden** | Methoden, die ein Objekt erstellen (`valueOf()`, `of()`) |
| **main-Methode** | Der Einstiegspunkt des Programms muss static sein |

Eine gute Faustregel: Wenn eine Methode **keine Instanzattribute** verwendet und **kein `this`** braucht, sollte sie `static` sein.

**Falscher Einsatz von static** (vermeide das):

```java
public class Patient {
    private static String name;  // FALSCH! Alle Patienten heißen gleich
}
```

`static`-Attribute gehören zur Klasse, nicht zum Objekt – 
alle Instanzen teilen sich denselben Wert.

**Achtung:** IntelliJ bietet oft Korrekturvorschläge für Compilerfehler an.
Es passiert immer wieder, dass IntelliJ vorschlägt, 
eine Methode `static` zu machen, 
obwohl das im Kontext nicht sinnvoll ist.
Du solltest bei den Korrekturvorschlägen immer prüfen, 
ob sie wirklich sinnvoll sind.

## Wichtige Regeln für static

| Zugriff | Instanzmethode | Klassenmethode (static) |
|---------|:---:|:---:|
| Kann Instanzattribute lesen/schreiben | ✓ | ✗ |
| Kann Klassenattribute lesen/schreiben | ✓ | ✓ |
| Kann andere Instanzmethoden aufrufen | ✓ | ✗ |
| Kann andere Klassenmethoden aufrufen | ✓ | ✓ |
| Hat Zugriff auf `this` | ✓ | ✗ |

```java
public class Example {
    private int instanceAttribute;
    private static int classAttribute;

    public void instanceMethod() {
        System.out.println(instanceAttribute);  // OK
        System.out.println(classAttribute);      // OK
        System.out.println(this.instanceAttribute);  // OK
    }

    public static void classMethod() {
        // System.out.println(instanceAttribute);  // Compiler error!
        System.out.println(classAttribute);        // OK
        // System.out.println(this.instanceAttribute);  // Compiler error!
    }
}
```

## Konstanten mit static final

In Python definierst du Konstanten auf Modulebene (z. B. `PI = 3.14159`). In Java verwendest du `static final`:

```java
public class MedicalConstants {
    public static final double NORMAL_TEMPERATURE = 37.0;
    public static final double MAX_SYSTOLIC_BLOOD_PRESSURE = 140;
    public static final int ID_LENGTH = 10;
}
```

Verwendung:

```java
System.out.println(MedicalConstants.NORMAL_TEMPERATURE);
```

## Vergleich Python vs. Java

| Konzept | Python | Java |
|---------|--------|------|
| Instanzmethode | `def method(self):` | `void method() { }` |
| Klassenmethode | `@classmethod def method(cls):` | `static void method() { }` |
| Klassenattribut | `attribute = value` (in Klasse) | `static type attribute = value;` |
| Konstante | `CONSTANT = value` (Konvention) | `static final TYPE CONSTANT = value;` |
| Zugriff auf Klassenmember | `Class.member` | `Class.member` |

## Zusammenfassung

### Wichtige Begriffe
- `static`
- Klassenmethode / Klassenattribut
- Instanzmethode / Instanzattribut
- `final` (Konstante)
- `static final`

### Das sollst du können
- Den Unterschied zwischen Instanz- und Klassenmembern erklären
- `static`-Methoden und -Attribute definieren
- Die Zugriffsregeln für `static` anwenden
- Entscheiden, wann `static` sinnvoll ist (Hilfsmethoden, Konstanten, Zähler)
- Konstanten mit `static final` definieren
