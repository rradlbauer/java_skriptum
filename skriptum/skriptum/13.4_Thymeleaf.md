# 13.4 Thymeleaf – Server-seitige Templates

**Thymeleaf** ist ein Template-Engine für die Darstellung von Webseiten. Die HTML-Templates liegen unter `src/main/resources/templates/`. Im Gegensatz zu rein statischen HTML-Seiten kann Thymeleaf Daten aus dem `Model` (Kapitel 13.1) direkt in die HTML-Ausgabe einfügen – der Server rendert die Seite, bevor sie an den Browser gesendet wird.

Thymeleaf-Arbeitsweise:

```
Controller liefert View-Name + Model-Daten
    → Thymeleaf findet das HTML-Template namens "patient-list.html"
        → ersetzt die th:-Attribute mit den Modell-Daten
            → statisches HTML wird an den Browser gesendet
```

## Namespace

Jedes Thymeleaf-Template deklariert den Thymeleaf-Namespace im `<html>`-Tag:

```html
<html xmlns:th="http://www.thymeleaf.org">
```

Damit erkennt Thymeleaf die `th:`-Attribute.

## Ausdrücke

| Ausdruck | Bedeutung | Beispiel |
|----------|-----------|----------|
| `${...}` | Variablen aus dem Model | `${patients}` |
| `*{...}` | Felder des aktuellen Objekts (in einem Formular) | `*{name}` |
| `@{...}` | URLs zu Pfaden der App | `@{/patients}` |

## Grundlegende Attribute

### Text anzeigen – th:text

```html
<td th:text="${p.name}"></td>
```

`th:text` ersetzt den HTML-Inhalt des Elements durch den Wert der Variable.

### Wiederholen – th:each

Eine Tabelle über alle Patienten erzeugen:

```html
<tr th:each="p : ${patients}">
    <td th:text="${p.name}"></td>
    <td th:text="${p.birthdate}"></td>
    <td th:text="${p.ssn}"></td>
</tr>
```

`th:each="p : ${patients}"` iteriert über `patients`; für jedes Element wird `<tr>` einmal gerendert, wobei `p` das aktuelle Element ist.

### Bedingungen – th:if

```html
<p th:if="${#lists.isEmpty(patients)}">No patients found.</p>
```

### Links – th:href

```html
<a th:href="@{/patients/register}">Register Patient</a>
```

### URLs mit Pfadparametern – @{...}

Um eine ID in die URL einzufügen, nutzt du die Klammer-Notation:

```html
<a th:href="@{/patients/{id}/vaccinations(id=${p.id})}">View</a>
```

`{id}` wird durch `p.id` ersetzt → `http://localhost:8080/patients/3/vaccinations`.

## Formulare

Thymeleaf bindet Formulare an Objekte. `th:object` setzt das Objekt, `th:field` bindet Eingabefelder:

```html
<form th:action="@{/patients/register}" th:object="${patient}" method="post">
    <input type="text" th:field="*{name}"/>
</form>
```

- `th:object="${patient}"` – das Objekt, an das das Formular gebunden ist
- `th:field="*{name}"` – bindet das Feld an das Attribut `name` des Objekts (setzt auch `name` und `id` des Input-Elements automatisch)
- `th:action="@{/patients/register}"` – wohin das Formular gesendet wird

Das `method="post"`-Attribut muss zur Controller-Methode passen (Kapitel 13.1 – `@PostMapping`).

## Validierungs-Feedback im Formular

Zusammen mit Bean Validation (Kapitel 13.3) zeigst du Fehler pro Feld an:

```html
<input type="text" th:field="*{name}"
       th:classappend="${#fields.hasErrors('name')} ? 'is-invalid'"/>
<div class="invalid-feedback" th:errors="*{name}"></div>
```

- `#fields.hasErrors('name')` – hat das Feld Fehler?
- `th:classappend` – fügt die CSS-Klasse `is-invalid` hinzu, wenn Fehler vorliegen
- `th:errors="*{name}"` – zeigt die Fehlermeldung aus der Annotation (Kapitel 13.3)

## Die Templates der Impf-Applikation

| Template | Zweck |
|----------|-------|
| `patient-list.html` | Alle Patienten in einer Tabelle anzeigen, Link zur Registrierung |
| `patient-register.html` | Formular zum Registrieren eines neuen Patienten |
| `vaccination-list.html` | Impfungen eines Patienten anzeigen |
| `vaccination-add.html` | Formular zum Hinzufügen einer Impfung |

## Zusammenfassung

### Wichtige Begriffe
- Template-Engine, serverseitiges Rendering
- `src/main/resources/templates/`
- Ausdrücke: `${...}`, `*{...}`, `@{...}`
- `th:text`, `th:each`, `th:if`, `th:href`, `th:object`, `th:field`
- `#fields` / Validierungs-Feedback

### Das sollst du können
- Erklären, wie Thymeleaf HTML mit Model-Daten rendert
- Daten mit `th:text` anzeigen und mit `th:each` wiederholen
- URLs und Pfadparameter mit `@{...}` erzeugen
- Ein Formular mit `th:object` und `th:field` an ein Objekt binden
- Validierungsfehler im Formular anzeigen
