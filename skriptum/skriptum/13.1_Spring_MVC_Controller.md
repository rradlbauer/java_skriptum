# 13.1 Spring MVC – Controller

**Spring MVC** (Model-View-Controller) ist das Modul von Spring, das HTTP-Anfragen verarbeitet. Es folgt dem **MVC-Muster**:

- **Model** – die Daten (z. B. die Liste der Patienten)
- **View** – die Darstellung (z. B. eine HTML-Seite, siehe Kapitel 13.4)
- **Controller** – nimmt Anfragen entgegen, verarbeitet sie und liefert Model + View

## Das MVC-Muster

```
HTTP-Request
    → Controller (verarbeitet, spricht mit Repository)
        → erzeugt Model (Daten) + wählt View aus
            → View rendert die HTML-Seite
                → HTTP-Response
```

Der Entwickler schreibt den **Controller** (Java) und die **View** (Thymeleaf-Template). Das **Model** ist meist ein Objekt der Klasse `org.springframework.ui.Model`, das der Controller mit Daten befüllt.

## @Controller

Eine Klasse, die HTTP-Anfragen entgegennimmt, wird mit `@Controller` markiert. Spring findet sie über `@ComponentScan` (Kapitel 13.0) automatisch:

```java
package com.health.vax.controller;

import org.springframework.stereotype.Controller;
import org.springframework.ui.Model;
import org.springframework.web.bind.annotation.*;

@Controller
public class PatientController {
    // ...
}
```

## Mapping-Annotationen

Mit **@GetMapping** und **@PostMapping** legst du fest, auf welche URL und mit welcher HTTP-Methode eine Methode reagiert:

```java
@GetMapping("/patients")
public String list(Model model) {
    return "patient-list";   // View-Name (Template in 13.4)
}

@PostMapping("/patients/register")
public String register(Patient patient) {
    return "redirect:/patients";
}
```

| Annotation | HTTP-Methode | Verwendung |
|------------|--------------|------------|
| `@GetMapping` | GET | Daten anzeigen, Formular anzeigen |
| `@PostMapping` | POST | Daten senden (z. B. Formular absenden) |

Diese Annotationen kombinieren `@RequestMapping` mit der jeweiligen HTTP-Methode.

## Model – Daten an die View übergeben

Der Controller befüllt das `Model`-Objekt und gibt den Namen der View zurück:

```java
@GetMapping("/patients")
public String list(Model model) {
    model.addAttribute("patients", patientRepository.findAll());
    return "patient-list";
}
```

`model.addAttribute("patients", ...)` legt Daten unter einem Namen ab. In der View (Kapitel 13.4) greifst du über `${patients}` darauf zu.

## @PathVariable – Werte aus der URL

Mit **@PathVariable** liest du Platzhalter-Werte aus dem URL-Pfad:

```java
@GetMapping("/patients/{patientId}/vaccinations")
public String list(@PathVariable Long patientId, Model model) {
    model.addAttribute("patient", patientRepository.findById(patientId).orElseThrow());
    return "vaccination-list";
}
```

Die URL `http://localhost:8080/patients/7/vaccinations` setzt `patientId = 7`. Der Platzhalter `{patientId}` muss dem Methodenparameter `@PathVariable Long patientId` entsprechen.

## @ModelAttribute – Formulardaten binden

Mit **@ModelAttribute** bindet Spring die Daten eines abgeschickten Formulars an ein Objekt. Die Formularfelder werden über die Getter/Setter dem Objekt zugewiesen:

```java
@PostMapping("/patients/register")
public String register(@ModelAttribute Patient patient) {
    patientRepository.save(patient);
    return "redirect:/patients";
}
```

Das Formular (Kapitel 13.4) sendet z. B. die Felder `name`, `birthdate`, `ssn`. Spring erzeugt ein `Patient`-Objekt und befüllt diese Felder automatisch.

## Redirect

`return "redirect:/patients";` veranlasst den Browser, eine neue GET-Anfrage an die angegebene URL zu senden. Das ist sinnvoll, nachdem Daten verändert wurden (PRG-Muster: **Post/Redirect/Get**) – so verhindert man, dass ein Refresh das Formular erneut abschickt.

## Aufbau der Impf-Applikation

Das Projekt verwendet zwei Controller:

- `PatientController` – `/patients`, `/patients/register`: Patienten anzeigen und registrieren
- `VaccinationController` – `/patients/{patientId}/vaccinations`: Impfungen eines Patienten anzeigen und hinzufügen

Beide greifen über **Spring Data Repositories** (Kapitel 13.2) auf die Datenbank zu.

## Zusammenfassung

### Wichtige Begriffe
- MVC (Model-View-Controller)
- `@Controller`
- `@GetMapping` / `@PostMapping`
- `Model` (`addAttribute`)
- `@PathVariable`
- `@ModelAttribute`
- `redirect:` / Post-Redirect-Get

### Das sollst du können
- Das MVC-Muster erklären
- Einen `@Controller` mit GET-/POST-Mapping schreiben
- Daten über `Model` an die View übergeben
- Werte über `@PathVariable` aus der URL lesen
- Formulardaten mit `@ModelAttribute` binden
- Den Unterschied zwischen direktem View-Aufruf und `redirect` erklären
