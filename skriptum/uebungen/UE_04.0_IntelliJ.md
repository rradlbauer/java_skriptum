### UE_04.0_3: Mit dem Debugger arbeiten

Erstelle eine Klasse `Blutdruck.java` mit folgendem Code:

```java
package com.example.hospital;

public class BloodPressure {
    public static void main(String[] args) {
        int systolic = 140;
        int diastolic = 90;

        System.out.println("Blood pressure: " + systolic + "/" + diastolic);

        if (systolic >= 140 || diastolic >= 90) {
            System.out.println("Elevated blood pressure!");
        } else {
            System.out.println("Normal blood pressure.");
        }

        System.out.println("Measurement complete.");
    }
}
```

1. Setze einen Breakpoint in Zeile 7 (int systolic = 140;)
2. Starte den Debugger
3. Gehe Schritt für Schritt durch das Programm (F8)
4. Beobachte, wie sich die Variablen ändern
5. Notiere, welche Ausgaben bei welchen Schritten erscheinen

### UE_04.0_4: Zahlen raten

Erstelle nun mit IntelliJ ein Spiel:

Das Programm ermittelt zuerst mit Hilfe der Klasse `java.util.Random`
eine Zufallszahl zwischen 1 und 100.
Ein Spieler kann immer wieder raten und eine Zahl eintippen.
Das Programm gibt dann die Information aus, ob die geratene Zahl
zu klein oder zu groß ist.
Sobald die Zahl richtig geraten wurde, gibt das Programm aus,
wie viele Versuche der Spieler benötigt hat.

**Fehlerbehandlung:**  
Wenn ein Benutzer versehentlich keine Zahl oder eine negative Zahl
bzw. eine Zahl über 100 eintippt, wird eine Fehlermeldung angezeigt,
und der Benutzer wird zur neuerlichen Eingabe aufgefordert. 
Der Fehlversuch wird nicht mitgezählt.
