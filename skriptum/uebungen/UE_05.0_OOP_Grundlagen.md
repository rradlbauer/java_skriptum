### UE_05.0_3: Von Python zu Java

Gegeben ist folgender Python-Code:

```python
class Patient:
    def __init__(self, name, birthDate, height, weight):
        self.name = name
        self.birthDate = birthDate
        self.height = height
        self.weight = weight

    def bmi(self):
        return self.weight / (self.height ** 2)

p = Patient("Anna", date(1990, 5, 15), 1.75, 70);
print(p.bmi());
```

Übersetze diesen Code nach Java. Achte auf:
- Die Klasse heißt genauso wie die Datei
- Konstruktor hat keinen Rückgabetyp
- `self` wird zu `this`
- `**` gibt es nicht – verwende `Math.pow()` oder einfache Multiplikation
