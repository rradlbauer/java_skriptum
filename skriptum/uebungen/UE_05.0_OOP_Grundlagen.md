### UE_05.0_1: Patient-Klasse

Erstelle eine Klasse `Patient` im Package `at.htl.medizin` mit folgenden Attributen:

- `name` (String)
- `geburt` (LocalDate)
- `diagnose` (String)
- `aufenthaltsdauer` (int, in Tagen)

Füge eine Methode `ausgabe()` hinzu, 
die alle Patientendaten formatiert ausgibt.

Füge eine Methode `berechneAlter()` hinzu, 
die das Alter des Patienten in Jahren berechnet und zurückgibt.

Erstelle in einer separaten `Main`-Klasse zwei Patient-Objekte, setze ihre Attribute und rufe `ausgabe()` auf.

### UE_05.0_3: Von Python zu Java

Gegeben ist folgender Python-Code:

```python
class Patient:
    def __init__(self, name, geburt, groesse, gewicht):
        self.name = name
        self.geburt = geburt
        self.groesse = groesse
        self.gewicht = gewicht

    def bmi(self):
        return self.gewicht / (self.groesse ** 2)

p = Patient("Anna", date(1990, 5, 15), 1.75, 70);
print(p.bmi());
```

Übersetze diesen Code nach Java. Achte auf:
- Die Klasse heißt genauso wie die Datei
- Konstruktor hat keinen Rückgabetyp
- `self` wird zu `this`
- `**` gibt es nicht – verwende `Math.pow()` oder einfache Multiplikation
