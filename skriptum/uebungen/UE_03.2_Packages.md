### UE_03.2_1: Projektstruktur mit Packages

Erstelle folgende Projektstruktur für ein kleines Krankenhaus-System:

```
hospital/
├── src/
│   └── com/
│       └── example/
│           └── medical/
│               ├── Patient.java
│               └── Hospital.java
└── bin/
```

Inhalt von `Patient.java`:
```java
package com.example.medical;

public class Patient {
    public static void display() {
        System.out.println("Patient from package com.example.medical");
    }
}
```

Inhalt von `Hospital.java`:
```java
package com.example.medical;

public class Hospital {
    public static void main(String[] args) {
        System.out.println("Hospital system starting...");
        Patient.display();
    }
}
```

1. Kompiliere beide Dateien mit: `javac -d bin src/com/example/medical/*.java`
2. Überprüfe die erzeugte Struktur im `bin`-Ordner
3. Führe das Programm aus: `java -cp bin com.example.medical.Hospital`

### UE_03.2_2: Import aus Package

Erstelle ein zweites Package `com.example.laboratory` mit einer Klasse `Lab.java`.
Importiere und verwende die `Lab`-Klasse in `Hospital.java`.

```java
package com.example.laboratory;

public class Lab {
    public static void loadLabData() {
        System.out.println("Loading lab data...");
    }
}
```

Füge in `Hospital.main()` den Aufruf `Lab.loadLabData();` hinzu.
