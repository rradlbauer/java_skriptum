### UE_05.4_1: Patientenverwaltung mit Zähler

Erweitere die Klasse `Patient` um:

- Ein privates statisches Attribut `patientCount` (int), das bei jedem neuen Patienten erhöht wird
- Eine öffentliche statische Methode `getPatientCount()`, die den aktuellen Wert zurückgibt
- Eine Instanzmethode `display()`, die die Patientendaten und die Gesamtzahl der Patienten ausgibt

```java
Patient p1 = new Patient("Anna", 25);
Patient p2 = new Patient("Ben", 30);
Patient p3 = new Patient("Clara", 28);

System.out.println(Patient.getPatientCount());  // 3
p2.display();  // "Ben (30) - Total: 3 patients"
```

### UE_05.4_2: Medizinische Konstanten

Erstelle eine Klasse `MedicalConstants` mit `static final`-Konstanten:

- `NORMAL_TEMPERATURE = 37.0`
- `FEVER_THRESHOLD = 38.0`
- `HYPOTHERMIA_THRESHOLD = 35.0`
- `MAX_SYSTOLIC_BLOOD_PRESSURE = 140`
- `MIN_SYSTOLIC_BLOOD_PRESSURE = 90`
- `BLOOD_SUGAR_NORMAL_MIN = 70.0`
- `BLOOD_SUGAR_NORMAL_MAX = 110.0`

Füge eine statische Methode `hasFever(double temperature)` hinzu, die prüft, ob die Temperatur über dem Fieber-Grenzwert liegt.

### UE_05.4_3: BMI-Rechner als statische Methode

Erstelle eine Klasse `BMICalculator` mit:

- Einer statischen Methode `calculateBMI(double weightKg, double heightM)`, die den BMI berechnet
- Einer statischen Methode `classifyBMI(double bmi)`, die einen String zurückgibt:
  - < 18.5: "Underweight"
  - 18.5 - 24.9: "Normal weight"
  - 25.0 - 29.9: "Overweight"
  - >= 30.0: "Obesity"
- Verwende die Klasse ohne ein Objekt zu erzeugen (nur über den Klassennamen)

### UE_05.4_4: Statisch vs. Instanz

Analysiere folgenden Code und beantworte die Fragen:

```java
public class Analysis {
    private int instanceValue;
    private static int staticValue;

    public void instanceMethod() {
        System.out.println(instanceValue);     // Frage 1: OK?
        System.out.println(staticValue);       // Frage 2: OK?
    }

    public static void staticMethod() {
        System.out.println(instanceValue);     // Frage 3: OK?
        System.out.println(staticValue);       // Frage 4: OK?
    }
}
```

Frage: Welche Zeilen sind OK, welche führen zu einem Compiler-Fehler? Begründe.
