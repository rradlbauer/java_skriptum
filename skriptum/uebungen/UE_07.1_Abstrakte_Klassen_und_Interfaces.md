### UE_07.1_1: Abstract class Examination

Erstelle eine abstrakte Klasse `Examination`:

```java
public abstract class Examination {
    protected String patientName;
    protected String date;

    public Examination(String patientName, String date) {
        this.patientName = patientName;
        this.date = date;
    }

    public abstract void perform();
    public abstract String getResult();

    public String getPatientName() {
        return patientName;
    }
}
```

Erstelle zwei konkrete Unterklassen:

1. `BloodTest`:
   - Zusätzliche Attribute: `bloodValue` (String), `measuredValue` (double)
   - `perform()` gibt aus: "Blood test for [patientName]: [bloodValue] = [measuredValue]"
   - `getResult()` gibt einen String mit dem Ergebnis zurück

2. `ECG`:
   - Zusätzliche Attribute: `heartRate` (int), `rhythm` (String, z. B. "Sinus rhythm")
   - `perform()` gibt aus: "ECG for [patientName]: [heartRate] bpm, [rhythm]"
   - `getResult()` gibt einen String zurück

### UE_07.1_2: Interface Treatable

Erstelle ein Interface `Treatable`:

```java
public interface Treatable {
    void treat();
    String getDiagnosis();
}
```

Implementiere das Interface in zwei unterschiedlichen Klassen:

1. `Patient` (hat Attribute: `name`, `diagnosis`, `age`)
   - `treat()` gibt aus: "Patient [name] is being treated for: [diagnosis]"
   
2. `Animal` (hat Attribute: `species`, `name`, `diagnosis`)
   - `treat()` gibt aus: "[species] [name] is being treated for: [diagnosis]"

Zeige in einer `main`-Methode, dass beide Klassen über das Interface angesprochen werden können.

### UE_07.1_3: Vaccinable and Examinable

Erstelle zwei Interfaces:

```java
public interface Vaccinable {
    void vaccinate(String vaccine);
    boolean isVaccinated();
}

public interface Examinable {
    void examine(String type);
    String lastFinding();
}
```

Erstelle eine Klasse `Dog`, die beide Interfaces implementiert (zusätzliche Attribute: `name`, `vaccinated`, `lastExamination`).

Erstelle in der `main`-Methode einen Hund und rufe Methoden beider Interfaces auf.
