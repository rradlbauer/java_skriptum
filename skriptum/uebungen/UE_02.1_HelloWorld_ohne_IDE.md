### UE_02.1_1: Erste Schritte mit Kommandozeile

1. Erstelle mit einem Texteditor (Notepad, VS Code, ...) eine Datei `MedicalWelcome.java` mit folgendem Inhalt:

```java
public class MedicalWelcome {
    public static void main(String[] args) {
        System.out.println("Welcome to Medical Informatics!");
    }
}
```

2. Kompiliere die Datei mit `javac MedicalWelcome.java`
3. Überprüfe, ob eine `MedicalWelcome.class`-Datei entstanden ist
4. Führe das Programm mit `java MedicalWelcome` aus
5. Dokumentiere jeden Schritt und die Ausgaben

### UE_02.1_2: Patientendaten ausgeben

Schreibe ein Programm `PatientOutput.java`, das folgende Patientendaten auf der Konsole ausgibt:

```
=== Patient Data ===
Name: Anna Müller
Age: 34
Diagnosis: Hypertension
Admission Date: 15.01.2024
```

Kompiliere und führe das Programm aus.

### UE_02.1_3: Scanner – Patientendaten einlesen

Schreibe ein Programm `PatientInput.java`, das:

1. Den Benutzer mit `Scanner` nach Name, Alter und Diagnose fragt
2. Die eingegebenen Daten formatiert mit `System.out.printf()` ausgibt
3. Den Scanner nach der Verwendung schließt

Beispiel-Ablauf:

```
Please enter name: Anna Müller
Please enter age: 34
Please enter diagnosis: Hypertension

=== Patient Data ===
Name:   Anna Müller
Age:    34 years
Diagnosis: Hypertension
```

### UE_02.1_4: Fehler erkennen

Gegeben ist folgender Code:

```java
public class ErrorTest {
    public static void main(String[] args) {
        System.out.println("Start of diagnosis")
        int patientId = "MK-0815"
    }
}
```

1. Versuche, diesen Code zu kompilieren
2. Notiere die Fehlermeldung(en)
3. Korrigiere die Fehler und führe das Programm aus
