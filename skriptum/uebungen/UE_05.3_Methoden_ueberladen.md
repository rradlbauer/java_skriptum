### UE_05.3_1: Dosierungsrechner

Erstelle eine Klasse `DosageCalculator` mit überladenen Methoden `calculateDose()`:

1. `calculateDose(double weight, double mgPerKg)` – einfache Dosierung
2. `calculateDose(double weight, double mgPerKg, int age)` – für Kinder unter 12 Jahren wird die Dosis halbiert
3. `calculateDose(String activeIngredient, double weight)` – schlägt anhand des Wirkstoffs den mgPerKg-Faktor nach (verwende if/else)
   - "Ibuprofen" → 10 mg/kg
   - "Paracetamol" → 15 mg/kg
   - "Amoxicillin" → 20 mg/kg
   - Default → 5 mg/kg

Teste alle drei Varianten in der `main`-Methode.

### UE_05.3_2: Überladene Konstruktoren

Erstelle eine Klasse `DoctorAppointment` mit folgenden Konstruktoren:

1. `DoctorAppointment(String patient, String date)` – Standardtermin (30 Minuten)
2. `DoctorAppointment(String patient, String date, int duration)` – Termin mit benutzerdefinierter Dauer
3. `DoctorAppointment(String patient, String date, int duration, String specialty)` – vollständiger Termin

Verwende `this(...)`, um Wiederholungen zu vermeiden.
Füge eine Methode `display()` hinzu, die alle Termindetails anzeigt.

### UE_05.3_3: Maximalen Puls berechnen

Die maximale Herzfrequenz kann auf verschiedene Arten berechnet werden:

1. Einfache Formel: `220 - age` (für Erwachsene)
2. Genauere Formel: `208 - 0.7 * age` (Tanaka-Formel)
3. Für Sportler: `205 - 0.5 * age`

Erstelle überladene Methoden `maxHeartRate()`:
- `maxHeartRate(int age)` – verwendet die einfache Formel
- `maxHeartRate(int age, boolean precise)` – wenn true, verwende Tanaka-Formel
- `maxHeartRate(int age, boolean precise, boolean athlete)` – wenn athlete true, verwende Sportler-Formel
